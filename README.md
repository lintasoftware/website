# Lintasoft — Company Website

A modern, responsive single-page website for **Lintasoft**, an IT solutions company.

## ✨ Features

- **About** — Company overview, mission, and key stats
- **Services** — Custom software, cloud, AI, cybersecurity, mobile apps, IT consulting
- **Products** — LintaERP, LintaCommerce, LintaChat, LintaLearn, LintaHealth, LintaShield
- **Contact Us** — Contact details and an inquiry form
- Fully responsive (mobile-friendly with hamburger menu)
- Smooth scrolling and scroll-based active navigation
- Pure HTML, CSS, and JavaScript — no build step required

## 🚀 Running Locally

Just open `index.html` in your browser, or serve it with any static web server:

```bash
# Python
python3 -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.
